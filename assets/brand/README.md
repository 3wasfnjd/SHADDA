# Aboden Games brand · هوية عبودين قيمز

`aboden-games-white.svg` is the approved studio logo (October 2026): two tilted rounded squares
above «عبودين قيمز» (Cairo Bold 700) and «ABODEN GAMES» (Cairo Medium 500), all outlined to paths,
white on transparent. Use it on dark or coloured backgrounds; it is the splash logo in Dahrooj
and the reference for every future Aboden Games title.
