# شدّة — SHADDA

لعبة واقع مختلط أصلية على Meta Quest 3 و3S من **عبودين قيمز / ABODEN GAMES**.

المشروع قيد التنفيذ باستخدام Godot وOpenXR. المرحلة الأولى تثبت مسار بناء APK عبر GitHub Actions، وتعرض Passthrough والشعار والقفازات قبل اختبارها على النظارة.

لا يوجد APK مُختبر على Quest في هذا الالتزام التأسيسي. تُنفذ المراحل على فروع وطلبات دمج، ويُفصل نجاح البناء عن الاختبار الفعلي على الجهاز.
