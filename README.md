# غارة صقر — SAQR Raid (نسخة الويب)

لعبة طيران من فوق (shoot-'em-up) من **عبودين قيمز / ABODEN GAMES**، صفحة HTML واحدة بدون مكتبات.

- `index.html` — اللعبة كاملة (الرسومات مضمّنة داخلها كـ WebP).
- `art/` — نسخ PNG شفافة من الرسومات المعتمدة (مقصوصة من ملفات صاحب المشروع) للرجوع لها.

**المحتوى:** 10 مراحل، 6 زعماء (الحصن الطائر، البارجة، الحصن الحديدي، المدمّرة، حصن الظلام، العملاق)، جوائز عائمة، 4 أسلحة بذخيرة، تحديات بالنجوم، حظيرة تطوير، قوائم زجاجية، شاشة تحميل.

**التحكم:** الجوال: اضغط واسحب (الإطلاق مع الضغط فقط). الكمبيوتر: الأسهم/WASD، الماوس أو J للإطلاق، المسافة للقنبلة، P إيقاف.

التقدم محفوظ في متصفح اللاعب فقط (localStorage).
