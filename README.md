# صقر — SAQR (v1.0)

لعبة واقع مختلط على Meta Quest 3 / 3S من **عبودين قيمز / ABODEN GAMES** — Godot 4.7 + OpenXR + Passthrough، تُبنى APK عبر GitHub Actions. لعبة مستقلة: لا تشارك كودًا ولا ستايلًا مع أي لعبة سابقة.

**طيارتك الحربية الكرتونية واقفة على أرض غرفتك. تقلع منها وتطير فعليًا حولك — كل شيء بيدك مثل الطيارات اللاسلكية.**

## البداية
1. شعار عبودين قيمز يظهر **مرة واحدة** كشاشة Meta الافتتاحية.
2. لوحة القائمة الرئيسية أمامك: **الحملة · الحظيرة · الإعدادات · طريقة التحكم**. أشّر بيد عصا الطيران واضغط الزناد.
3. (مسح الغرفة متوقف حاليًا: اللعب فوق أرضية مفتوحة.)

## الحملة — طلعة واحدة متواصلة، 8 مهام، 3 نجوم لكل مهمة
زر **انطلق** يبدأ من أول مهمة ما خلصتها، والمهام تتتابع وأنت في الجو: بطاقة النجوم والذهب ثم المهمة التالية مباشرة. إذا فشل الهدف تُعاد المهمة فورًا. كل المعركة **أمامك** داخل ساحة محددة بعلامات على الأرض، والأعداء يدخلون من الأمام.

| 1 | مدرسة الطيران | 8 حلقات بالترتيب ثم بالونات (مع تلميحات) | 1:40 / 1:10 |

كل مهمة تفتح التي بعدها. الذهب من المهام يشتري من الحظيرة.

## الحظيرة
- **تطويرات (3 مستويات)**: المحرك، الهيكل المدرّع، الرشاشات، الصواريخ.
- **الرشاش (الزناد)**: مزدوج · رباعي حارق (يشعل العدو) · مدفع 20 ملم (كل طلقة تنفجر).
- **السلاح الخاص (A)**: قنابل · عنقودية · ألغام جوية (للملاحقين) · الصاعقة (برق يقفز بين 4 أعداء).
- **مشاعل التمويه**: اللفّة (B) تطلق مشاعل تخدع صواريخ الدفاع الجوي.

## الطيران
| | |
|---|---|
| العصا اليسرى ↑↓ | البنزين — ←→ الدفة |
| العصا اليمنى ↑↓ | ↑ صعود / إقلاع، ↓ نزول / هبوط — ←→ ميلان |
| الزناد الأيمن | رشاشات الجناح اليمين · **القبضة** اقفل ثم اترك للصواريخ |
| A | السلاح الخاص · **B** لفّة مراوغة |
| X / Y (اليسرى) | دوران للخلف U · حلقة كاملة |
| الزناد الأيسر | رشاشات الجناح اليسار · **القبضة اليسرى** تسريع في الجو وفرامل على الأرض |
| ☰ (الأيسر) | إيقاف مؤقت |

يمكن قلب اليدين من الإعدادات (عصا الطيران باليسرى). على الأرض متوقفة: تتصلح وتعيد التعبئة.

## الصعوبة والخسارة
- **سهل**: الطيارة ما تتحطم (الضرر يقف عند 15%).
- **عادي / صعب**: إذا انضربت تتفكك الطيارة قطعًا (أجنحة، ذيل، مقدمة، جسم) تحترق وتتطاير وتستقر على الأرض، والطيار يقفز بالمظلة. الصعب: أعداء أشرس وذهب ×1.5.

## الإعدادات
اللعب (اللغة، الصعوبة، مسح التقدم) · التحكم (يد العصا، عكس المحور، الحساسية، اعتدال الأجنحة، مساعدة التصويب، الاهتزاز) · الرسوميات (متوازنة/عالية/فائقة، 72/90/120Hz، المؤثرات) · الصوت (الموسيقى، المؤثرات).

## الفصل بين الحالات
دائمًا: **تم البناء** / **تم فحص الحزمة** / **نجحت الاختبارات الآلية** / **تم التثبيت على Quest بواسطة صاحب المشروع** / **تم اختبار اللعب بواسطته**. صور `build/previews/` معاينة مكتبية، ليست من النظارة.
