# تراخيص الأصول والاعتمادات

- موديل الطيارة (vintage propeller airplane) وموديل السلاح (vintage weapon): قدّمهما صاحب المشروع لهذه اللعبة. النسخ في `assets/models/source/` مخففة ومفكوكة الضغط بـ gltfpack (meshoptimizer, MIT)، والنسخ داخل اللعبة معالجة بأدوات `tools/import_*.gd`. حقوقها لصاحبها ولمصدرها الأصلي، ولا يُعاد ترخيصها هنا.
- ملفات WAV: تركيب برمجي أصلي بـ `tools/generate_audio.py` و`tools/generate_music.py`؛ CC0-1.0 من جانب هذا الكود. لا تسجيلات ولا موسيقى مقتبسة.
- الموديلات الكرتونية الأخرى: مبنية برمجيًا في `systems/models.gd` لهذه اللعبة.
- شعار الاستوديو «عبودين قيمز / ABODEN GAMES»: نص بخط Baloo Bhaijaan 2 (© 2019 The Baloo 2 Project Authors / Ek Type — SIL OFL 1.1، النص في docs/baloo-OFL.txt). الخط نفسه في assets/fonts ويُستخدم للأرقام داخل اللعبة.
- Godot: MIT، والإضافة Godot OpenXR Vendors: MIT؛ تراخيصها مرفقة بتوزيعاتها.
